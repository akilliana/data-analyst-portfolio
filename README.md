# Введение

Проект состоит из двух разделов:

1.  A/B - тестирование изменения дизайна главной страницы музыкального стримингового сервиса ([датасет](https://www.kaggle.com/datasets/zhangluyuan/ab-testing))
2.  анализ продаж и пользовательского поведения на e-commerce платформе ([датасет](https://www.kaggle.com/datasets/abhayayare/e-commerce-dataset)).

В ходе анализа были исследованы:

- влияние дизайна на конверсию пользователей
- динамики денежных метрик в разрезе заказов и категорий
- ключевые метрики когорт
- события

Персональные пользовательские данные (имена, email, gender) не использовались в анализе.

# Структура данных

## 1. A/B - тестирование

Датасет представляет собой таблицу из пяти столбцов:

- user_id
- timestamp
- group - control/treatment
- landing_page - new_page/old_page
- converted - 1/0

## 2. Анализ e-commerce платформы

Датасет представляет собой несколько таблиц:

- users - данные пользователей
- products - данные о товарах
- orders - данные о заказах
- order_items - данные о составе заказа
- reviews - данные об отзывах
- events - данные о событиях

# Основные этапы анализа

## 1. A/B - тестирование

### Постановка задачи

- определение метрики для оценки
- формулировка гипотез
- указание уровня значимости, мощности теста и MDE

### Exploratory data analysis

- определение основные статистические величины
- проверка наличия дубликатов и пропусков
- проверка наличия несоответствующих значений
- проверка соответствия принадлежности групп к определенной странице
- очистка несоответствующих данных

### Оценка размера выборки

(т.к. проект выполнялся по готовому датасету, размер выборки не устанавливался перед тестом, а проверялся на соответствие уже непосредственно перед расчетом z-теста)

### z-тест

- расчет z-тест
- расчет p-value

## 2. E-commerce

### Оценка качества данных

- оценка размера таблиц
- проверка уникальности ключевых полей
- проверка наличия NULL-значений
- проверка дубликатов
- проверка диапазонов значений
- проверка согласованности таблиц
- оценка согласованности агрегатов

### Exploratory data analysis

- продажи (orders, GMV, AOV)
- товары (GMV, orders по категориям)
- когорты (RR, GMV, ARPPU, LTV)
- событийная аналитика (MAU, MAC, CR)
